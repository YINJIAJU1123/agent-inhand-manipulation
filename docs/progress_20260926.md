# Project progress — 2026-09-26

## Current research direction

The project is being organized around **language-guided active in-hand search**:
given a language target, the hand should search for a marked surface that may be
initially hidden, expose it to the camera, and maintain a stable display.

The privileged state teacher is treated as a frozen control oracle and data
generator. The paper-facing problem is the observation-limited actor: it must
use camera observations, language, proprioception, and history without receiving
object pose, target-face IDs, or hidden layout state.

## What is currently in place

- Revo3 semantic reorientation task with a 21-D action interface.
- Camera-enabled RGB-D collection path at 256x256.
- State-teacher rollout collection with episode, target, action, proprioception,
  terminal, and checkpoint provenance metadata.
- Deterministic RGB feature baselines and a recurrent visual-language student.
- Semantic-search pilot with six colored surface markers and randomized layouts.
- Disjoint layout splits: 576 train, 72 validation, and 72 test permutations.
- Visible/hidden reset conditions, depth-tested visibility, projected-area and
  facing checks, stable-display dwell, drop accounting, and per-slot episode
  quotas.
- `scripts/rsl_rl/run_teacher_stage.sh` for repeatable teacher smoke,
  evaluation, hold, and training stages.

## Evidence boundary

The visual-language student results are diagnostic only. The current merged
teacher replay contains 387 episodes and 10,880 aligned samples. The
marker-aware 36-D RGB fallback produced 0–8.33% success in 24-episode closed
loop tests depending on action scale; these results are not final paper claims.

The semantic-search outputs currently available in this checkout are smoke
tests and protocol checks. A completed multi-seed training/evaluation table for
the search task has not yet been produced.

The deterministic marker features are not SigLIP results. The intended SigLIP2
cache was not produced because the remote model download was unavailable.

## Next milestones

1. Freeze one state-teacher checkpoint, action contract, and evaluation protocol.
2. Build the oracle ladder: privileged state, target-face oracle, visual pose,
   and language-conditioned observation-limited control.
3. Finish a converged plain recurrent PPO baseline on visible and hidden
   search conditions.
4. Implement surface-level evidence memory with the same encoder, reward,
   parameter budget, and PPO budget as the plain-history baseline.
5. Evaluate scan, plain history, evidence memory, and oracle controls on
   paired initial states with at least three training seeds.
6. Add unseen layouts, unseen object geometries, temporary occlusion recovery,
   and RGB-only/RGB-D ablations after the core comparison is stable.

## Reproducibility notes

Run records should keep the code revision, dirty state, checkpoint SHA-256,
environment configuration, seed, layout split, object split, action scale,
episode quota, and metric thresholds. Use a fresh output directory for every
run. Smoke completion does not imply that the task was learned.


## Visual-stage freeze (2026-09-26)

For the visual-student pipeline, the teacher is frozen to `model_1999.pt`
(SHA-256 `193129f874f81bca34a42e309c77612eb11ea29d7e2b4a60a5e8870536f9f707`)
from the hold-aware candidate run. The student action head emits a bounded
21-D command and the live evaluator uses normalized commands with the frozen
action scale `1.0`. The exact contract is versioned in
`configs/visual_student_freeze.json` and `docs/visual_student_protocol_v1.md`.
This freeze makes the visual experiments comparable; it does not upgrade the
single-seed teacher result into a final multi-seed paper claim.

The first evidence-memory model variant is now implemented in
`algo/agentic/visual_student.py`: the 36-D semantic frontend is split into six
surface slots and instruction-conditioned attention is added before the same
GRU/action budget. It is an experimental model variant until the live three-seed
comparison is completed; no performance claim is made yet.

## Visual student update (2026-09-30)

The camera and action contracts are now aligned with the frozen teacher. A
second DAgger round collected 23,872 RGB-D samples by letting the round-1 plain
student drive while the frozen teacher labeled visited states. The merged
round-2 cache contains 53,338 samples across 844 episode groups. On a quick
24-episode check, the round-2 plain model reached 14/24 (58.33%) success with
8/24 drops; the evidence model reached 12/24 (50.00%) with 10/24 drops. This
improves substantially over round 1, but the visual student is not yet stable
enough for a final CVPR result. The next validation should use a larger paired
evaluation before deciding whether another DAgger round is necessary.


## Visual student update (2026-09-30, rounds 3--4)

The larger 96-episode check showed round-2 plain at 37.50% success and 45.83%
drops, so two more DAgger rounds were run. Round 3 reached 52.08% success and
39.58% drops. Round 4 collected 19,648 samples with 165/240 teacher-success
episodes and produced a 95,002-sample aggregate. Its evidence-memory student
reached 73/96 (76.04%) success with 18/96 (18.75%) drops; plain reached
55/96 (57.29%) with 34/96 (35.42%) drops. Evidence is now the leading visual
candidate. Failures are concentrated on target faces 4 and 5, so the next
experiment should target those face-conditioned states instead of blindly
adding more uniform rollouts.


## Visual student update (targeted supplementation)

A target-face filter was added to `collect_dagger_rollouts.py`. Using the
round-4 evidence policy, a targeted face-4/5 shard added 15,043 samples. A
unified evidence model trained on the resulting 110,045-sample cache reached
79/96 (82.29%) success with 15/96 (15.63%) drops. Face 5 improved to 93.75%
and face 4 to 85.71%; faces 2 and 3 are now the limiting directions. The
student is ready for larger training and paired evaluation, but the frozen
teacher's 90%+ stability level has not yet been matched.


## Large-training entry check

The unified evidence dataset was trained with three seeds. On identical 96-episode
evaluations, seeds 1/2/3 reached 82.29%/70.83%/79.17% success, with drop rates
15.63%/20.83%/16.67%. The mean is 77.43% (5.0 points standard deviation).
This is sufficient to enter larger paired training and evaluation, but it is
not yet equivalent to the frozen teacher's stability.

## 2026-09-30: VisERDex-style student candidate frozen

The seventh DAgger round targeted the remaining face-2/3 coverage gap and added 15,155 RGB-D samples. The unified cache now has 139,507 samples and 2,128 episode groups. Three evidence seeds reached 83.33%, 86.46% and 83.33% on the fixed 96-episode visual protocol (mean 84.38%, standard deviation 1.47 points). The seed-3 checkpoint is the current stable VisERDex-style Revo3 visual-language student candidate. A later face-1/3/5 diagnostic round reached 82.29%, 88.54% and 77.08%, so it was rejected for higher seed variance. Full details are in `docs/visual_student_dagger_round7_report_20260930.md`.

## 2026-10-01: Long-horizon student check

A stricter 192-episode evaluation was run after the round-8 targeted DAgger update. Evidence seeds 1, 3 and 5 reached 80.73%, 85.94% and 82.29% success (mean 82.99%, standard deviation about 2.6 points). The frozen teacher reached 98.96% on the same reset seed with 96 episodes. The seed-3 round-8 checkpoint is now the long-horizon VisERDex-style student candidate. Full details are in `docs/visual_student_long_eval_report_20261001.md`.
