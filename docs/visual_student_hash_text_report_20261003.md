# Hash-text language-conditioned student (2026-10-03)

## Motivation

The frozen SigLIP2 path remains unavailable on the GPU host because the Hugging Face model download times out. To continue the language-conditioned stage without mislabeling the result, this run uses a deterministic, versioned text-string adapter.

The adapter hashes word and character n-grams from a canonical face instruction into a normalized 64-D vector. During cache generation, the canonical sentence is reconstructed from the target-face label. During live evaluation, the instruction is parsed to a face and then reconstructed as the same canonical sentence. This is a feature-interface test; it is not a test of paraphrase understanding or a pretrained semantic language model.

## Contract

- Visual task: `BrainCo-Direct-Revo3-VisualSemanticReorient-Cube-v0`
- RGB-D feature width: 1,060
- Language feature width: 64
- Language mode: `hash`
- Action dimension: 21
- Action scale: 1.0
- Vision stride: 2
- History: 8 observations
- Data: round-8 unified cache, 152,657 samples and 2,379 episode groups
- Evaluation: 96 episodes, four environments, 600-step horizon

The training cache is generated by `scripts/vision/cache_hash_text_features.py`. The closed-loop evaluator requires `--language-mode hash`, and checkpoints now record the language mode to prevent accidental one-hot/hash mismatch.

## Closed-loop result

| Seed | Success | Drop |
|---:|---:|---:|
| 1 | 86.46% | 12.50% |
| 3 | 81.25% | 14.58% |
| 5 | 80.21% | 13.54% |

Mean success is **82.64%** with approximately **2.7 percentage points** standard deviation. This is comparable to the one-hot language condition on the same 96-episode budget. It shows that a canonical text-derived feature can replace the one-hot goal without breaking the visual control path. It does not show that raw or paraphrased instructions are understood by the policy.

## Current interpretation

The hash-text run is an interface milestone. It does not establish open-vocabulary semantic understanding. The next test is to pass the raw instruction string into the evaluator and train with diverse, held-out paraphrases, including language-shuffle and zero-language controls. A versioned frozen CLIP/SigLIP text encoder can then replace the hash adapter while keeping the 21-D action head and evaluation protocol.
